# Miray & Ramazan Dijital Davetiye

GitHub Pages için hazır statik site.

## Yayınlama
1. GitHub'da yeni bir public repository oluşturun.
2. Bu klasörün içindeki dosyaların TAMAMINI repository köküne yükleyin.
3. Repository > Settings > Pages bölümüne girin.
4. Build and deployment: Deploy from a branch.
5. Branch: main, folder: /(root), Save.
6. Birkaç dakika sonra GitHub Pages adresiniz oluşur.

Ana dosya `index.html` repository'nin kökünde kalmalıdır.
